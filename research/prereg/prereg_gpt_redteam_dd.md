## 연구 1
- 데이터: 상폐 종목을 날짜별 RS universe에 넣고 생존주 RS도 전부 다시 계산(필수). 거래대금은 실제 → 없으면 비수정 종가×거래량 → 불가하면 '불명' 표시(수정주가×거래량 금지). 일반 하한가 잠김(시가=고가=저가=종가에 준함, 하한가)은 미체결·이월. 정리매매엔 가격제한 미적용(잠김 규칙 쓰지 않음). 합병·이전·SPAC: 실제 교환가치 복원 가능하면 사용, 불가면 Primary = 완전 추적 가능한 것만, 마지막 정상 거래일 강제청산은 별도 민감도(좋은 쪽 고르지 않음).
- RS 정의·BASE·K10·비용·청산 불변. RANDOM 10,000(seed_j = SHA256(prereg_hash‖j) 앞 64bit).
- 지표: 기존 TopKLift 정의 + 계좌 CAGR·MAR·MDD·Sharpe random 백분위. stationary bootstrap 평균 블록 20일 10,000회(같은 날 거래 함께).
- 강하게 통과(전부): 정정판 전체 TopKLift ≥ +0.135R · 95% CI 하단 > 0 · CAGR·MAR random ≥ 99백분위 · 4개 기간(2015~18 / 2019~22 / 2023~25.05 / 2025.06~) 중 3개 이상 TopKLift > 0 · 어느 기간도 ≤ −0.15R 아님 · 비용 0.6%에서 CAGR·MAR random ≥ 95백분위.
- 부분 통과: TopKLift > 0이나 CI가 0 포함 · 백분위 90~99 · 효과 25~50%만 남음.
- 편향 가능성 높음(하나라도): TopKLift ≤ 0 · CI 상단 ≤ 0 · CAGR·MAR 둘 다 90백분위 미만 · TopKLift < +0.0675R & CI가 0 포함 · 우월성이 한 기간에만 남음.
- 사전 예측: 생존편향 수정 시 RANDOM이 더 손해(확신 중간 이하).

## 연구 2 (BASE·RS 순·K10·0.5% 불변, 신규 포지션 위험만 0.25%로)
- H1 고변동성: 종목 소속 시장 지수 RV20_{t−1}(연율) > t−2까지 과거 756일 RV20의 80백분위 → 0.25%. 756일 미만 → 0.5%. 보유 포지션 조정 없음.
- H2 약한 폭: 시장별(코스피/코스닥) 거래 대상 중 종가>EMA20 비율 Breadth20_{t−1} < 과거 756일(t−2까지) 30백분위 → 0.25%.
- H3 상관 쏠림: 후보와 기존 보유 각각의 60일 일별 수익 상관(t−1까지, 최소 50일). corr ≥ 0.70인 보유가 3개 이상 → 0.25%. 데이터 부족 → 0.5%. 건너뛰지 않음.
- 대조: B0 · Hi · 평균 일별 포트폴리오 위험 노출을 Hi와 같게 맞춘 일정 위험 계좌. placebo: 0.25% 적용 개수를 같은 연도×시장 안에서 무작위 재배치 10,000회.
- 채택(전부): CAGR ≥ B0의 90% · MDD 크기 ≥ 20% 감소 · MAR ≥ +25% · 같은 노출 대조 대비 MAR ≥ +10% & MDD 5%p↑ 개선 · placebo MAR ≥ 95백분위 · Holm(3개) p < .05 · 4개 기간 중 3개 이상 MAR 개선 · 비용 0.6%에서 MAR이 B0보다 나빠지면 탈락. 여러 개 통과해도 조합 금지 → V1.1 shadow 후보만.
