# 신호가 넘칠 때 고르는 순서 — Claude 사전 등록 (2026-10-10 KST, GPT 답·결과 보기 전)

배경: 최대 10종목 계좌에서 지금 신호(S0)가 넘쳐 12년간 2만 건 넘게 자리가 없어 못 샀다. 지금 순서 = 상대강도(RS) 높은 순.
이 파일은 결과를 본 뒤 고치지 않는다.

## 고정 조건
- 신호 = 지금 매수 규칙(S0) 그대로. 청산·비용(0.3%)·같은 종목 보유 중 무시 그대로.
- 계좌: (1) 위험 0.5%/손절폭, 최대 10종목, 명목 한도 없음 (2) 동일금액 1/10, 현금 한도. 기간 A 2015.07~22 / B 2023~25.05 / C 2025.06~ 따로(자본 1에서 시작) + 전체 연속.
- 같은 날 후보만 순서를 정한다(보유 종목을 바꿔 타지 않음).

## 순서 가설 (같은 값이면 종목코드 순)
- R1 손절폭 작은 순: 손익비가 좋고 변동성이 낮은 자리 먼저. (주의: 같은 데이터에서 "손절폭 3% 이하가 R이 높다"는 걸 이미 봤다 → 사전 정보 오염 있음, 그래서 기준을 더 엄격히)
- R2 거래대금(20일 평균) 큰 순: 기관 참여가 많고 잡음이 적은 종목 먼저.
- R3 20일선 이격 작은 순: 덜 늘어난(과열 덜 된) 자리 먼저.

## 비교
- 지금 순서(RS 높은 순)
- 무작위 순서 500번(같은 날 후보를 무작위로 섞음) → 연수익·MAR 분포

## 채택 기준
1. 기간 A에서 MAR(연수익/최대낙폭)이 무작위 500번의 90백분위 이상 (R1은 사전 정보 오염 때문에 95백분위)
2. B·C에서 무작위 중앙값보다 MAR이 높음(방향)
3. 지금 순서(RS)보다 3기간 중 2기간 이상 MAR이 높고, 어느 기간도 최대낙폭이 3%p 넘게 나빠지지 않음
4. 두 계좌 방식 모두에서 1~3 성립
- 추가 확인(판정엔 안 씀): 지금 순서(RS)가 무작위 분포의 몇 백분위인지 — 지금 순서가 무작위와 다를 바 없다면 그것도 중요한 결과.
