# 시험 B 사전등록 — 응축이 V1.0에 도움이 되나 (2026-10-11 KST)

2023-01-01 ~ 2026-10-08 결과를 보기 전에 고정. 연습 = 2015-07-01 ~ 2022-12-31, 출력 `out_B_dev.txt`.
응축 = 볼린저(20일, 2σ, 모집단 표준편차) 폭 4·std/mean ≤ 최근 120봉(오늘 포함, 유효 60개↑) 폭의 아래 20%. "신호 전 응축" = t-4~t 중 하루라도(그날까지 자료만).

## 미리 밝혀 둘 오염
- 이전 연구(research/pattern_val)에서 "20일 신고가 돌파 + 응축"의 2023~ 결과(R +0.09, 구간 [−0.04,+0.33])를 이미 봤다. V1.0 신호 안의 2023~ 숫자는 아직 안 봤음.

## 연습 구간 숫자
- 신호(겹침 뺌) 7,639건, 응축 있음 2,644건(35%): R +0.109 vs −0.076, 차이 +0.185 [+0.004, +0.380], 응축 있음이 나은 해 7/8.
- 계좌(2015.07~22 따로 시작): 기준 연 +6.9% 낙폭 −51% MAR 0.14 · (2) 응축 먼저 +2.3% / −56% / 0.04 (나쁨) · (3) 응축만 +10.4% / −47% / 0.22 · 무작위 같은 비율 대조 200번 중 (3) 100백분위.

## 가설 (2개)
- **H-B1 (신호)**: 2023~에서 응축 있음 − 없음 평균 R > 0이고 날짜 묶음 부트스트랩 95% 아래끝 > 0. 그리고 2023·2024·2025·2026 중 3년 이상 응축 있음이 낫다.
- **H-B2 (계좌)**: 2023~(따로 시작)에서 (3) 응축 신호만 계좌가 (1) 기준보다 연수익과 MAR 둘 다 높고, 낙폭이 3%p 넘게 나빠지지 않으며, 무작위 같은 비율 대조 200번 중 MAR 90백분위 이상.
- (2) 응축 먼저 순서는 연습에서 이미 기준보다 나빠 기각. 시험 구간 숫자는 참고로만 출력.

## 판정과 규칙 변경
- 둘 다 통과 → "효과 있음"이지만 (3)은 거래를 크게 줄이는 변경이므로 바로 바꾸지 않고, 사용자에게 장단점(줄어드는 거래·빠지는 큰 수익)을 보여 주고 묻는다.
- 하나만 통과 → "약함", 규칙 그대로(화면 표시 참고만).
- 둘 다 실패 → "효과 없음", 규칙 그대로.
