# 2023~ 확인 전에 고정한 가설 (2026-10-11 KST, dev 2015-07~2022 결과만 보고 작성)

기준: 기본조건(종가>EMA20>EMA60, 거래대금 20일 평균 30억↑) · 상승·횡보장. 코드(s2_detect.py, s3_eval.py)는 이 시점 그대로 test에 한 번 돌린다.

dev에서 본 것
1. 박스·수렴선·채널 돌파는 같은 날 20일 신고가 돌파(H20)보다 낫지 않다 (Δr10·ΔR 95% CI가 0을 포함). 상승 채널은 H20보다 나쁘다(ΔR −0.10).
2. 무작위(같은 날 기본조건 전체 평균) 대비로는 수렴선 돌파가 r10 +0.3%p, R +0.1 정도 — 하지만 H20도 R +0.09라 "돌파 일반" 효과.
3. 돌파 직전 5일 안 응축이 있으면 추세 청산 R이 +0.12~0.19 높다 — 박스·수렴선·20일 신고가 모두 비슷 → 모양 효과가 아니라 응축 효과.
4. 거래량 1.5배↑는 박스·수렴선 r10을 +0.5%p 정도 올리지만 H20에서는 아님. R에서는 일관되지 않음.

test 판정 규칙
- 모양이 "효과 있음" = test에서도 H20 대비 ΔR 또는 Δr10 의 95% CI가 0 위, 방향이 dev와 같음.
- 응축 보조 효과 "있음" = test에서 H20 안 응축 있음−없음 ΔR CI가 0 위.
