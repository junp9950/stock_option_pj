## 사이트 코드 (저장소 `backend/`)
- `backend/services/stock_signals.py`
  - `_close_scores()` — **종가 매수 신호의 본체**. V1.0 매수(`buy`), 과열 매수(`hot`), 반도체 특별(`semi`), 주도주(`lead`)와 자리 표시(`lead_state`: 📍/🚀/⚠️), RS 계산
  - `signals()` — 종목 차트에 신호를 거슬러 찍는 함수(지난 날짜는 `rs_hist()`의 날짜별 RS 사용)
  - `_tracking()` — 최근 20일(주도주 60일) 신호를 규칙대로 따라간 "신호 추적"
  - `market_breadth()` — 시장 폭(50일선 위 비율 등)
- `backend/services/forward_log.py` — 앞으로의 실전 기록(가상 계좌 P/S/X/L/Lsh/Z). `_step()`이 체결·손절·청산 규칙
- `backend/services/close_entry_alert.py` — 15:12 텔레그램 종가 매수 알림
- `backend/screener/market_regime.py` — 시장 국면(상승/횡보/하락) = 전종목 같은 무게 지수가 20일선 위인지 + 기울기

## 규칙 요약 (V1.0, 코드가 정답 — 다르면 코드 기준)
- 시장 필터: 국면이 상승·횡보일 때만 신규 매수
- 대상: 거래대금 20일 평균 30억↑, 종가 > EMA20 > EMA60
- RS: 0.4×3개월 + 0.2×(6·9·12개월) 수익률을 위 대상 안에서 백분위(1~99)
- 매수: RS 70~95 + 손절폭(신호일 저가×0.99) ≤ 8% + (7개 조건 점수 6↑ | 이평선 모였다 돌파 | 과열 매수(점수 5, 빠진 게 과열 2개뿐 → 수량 절반))
- 주도주(L, 별도 소량): 정배열 + RS 95↑ + 손절폭 ≤ 8% + 양봉 + 종가가 그날 범위 위 절반, 거래당 위험 0.10%, 최대 2종목
- 체결: 신호일 **종가** 매수(실전은 15:12 장중 값으로 판단 → 종가 체결)
- 손절: 신호일 저가×0.99 예약(장중 닿으면, 시가가 아래면 시가) · 청산: 종가 < EMA21 → 다음 날 시가
- 비용: 매수 0.05% + 매도 0.25% · R = 순수익률 ÷ 손절폭
- 계좌: 10칸, 거래당 위험 0.5%, 같은 날 후보가 남은 칸보다 많으면 **RS 높은 순**

1. `results/redteam_run_out.txt`의 "다음 날 시가 진입: RS 연 +33.7%" 줄은 **나중에 찾은 미래 정보 버그**(다음 날 RS를 써서 고름)가 있던 결과입니다. 고친 뒤에는 종가 진입보다 낮았습니다.
